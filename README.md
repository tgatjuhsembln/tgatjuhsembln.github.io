# Kim’s portfolio

Static portfolio with a seamless animated object reel, English/Indonesian language switch, and portrait section.

## Publish with GitHub Pages

1. Create a public repository in your GitHub account.
2. Upload the contents of this folder directly into the repository root. `index.html` must be at the top level, beside `styles.css`, `app.js`, `projects.js`, and `media/`.
3. Open **Settings → Pages**.
4. Set **Source** to **Deploy from a branch**, choose **main** and **/ (root)**, then save.
5. Wait for the Pages deployment to finish. GitHub displays the final URL on the Pages settings screen.

A repository named `YOUR-USERNAME.github.io` publishes at `https://YOUR-USERNAME.github.io/`. Other repository names publish at `https://YOUR-USERNAME.github.io/REPOSITORY/`. All website asset paths are relative, so both layouts work.

## Add work

Edit `projects.js` and place matching assets in `media/`. The animated reel uses transparent `objectVideo` WebM and `objectPoster` PNG files. Original MP4s are used in the full video player.

This export contains website files only. It excludes Sites credentials, hosting manifests, Git history, and temporary processing files.
